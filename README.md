# DOWNitUP Desktop Releases

Static GitHub Pages site for DOWNitUP desktop downloads.

The large installer files should be uploaded as GitHub Release assets, not committed to git.

## Current Release

- Version: `1.0.0`
- macOS DMG: `DOWNitUP-1.0.0.dmg`
- SHA256: `abaeb7c876954bdb09a6a2ee7185a1a8209490677455db21fdfb6e008232bc1e`

## Publish Flow

1. Commit changes to `main`.
2. Create or update GitHub release `v1.0.0`.
3. Upload the DMG and `.sha256` file as release assets.
4. Enable GitHub Pages from the `main` branch root.
